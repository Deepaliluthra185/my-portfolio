# Deepali Luthra Portfolio

A responsive, single-page portfolio starter inspired by the supplied reference. It uses an original abstract monogram illustration rather than the person in the reference image.

## Customize before publishing

The main page content is in `src/App.tsx`. Search for the visible labels `EDITABLE INTRO`, `Placeholder`, `YOUR_EMAIL_ADDRESS`, and `add yours` to find content that needs your details.

- Replace the intro, biography, capability descriptions, and tool names with accurate information.
- Replace or remove each sample work card and its abstract artwork.
- Replace `YOUR_EMAIL_ADDRESS` and the social URL prompts in the contact area.
- Update the page description and social sharing description in `index.html`.

The contact form is a local starter only: it does not send or store messages. Add a verified contact address or connect a form service before relying on it.

## Run in this workspace

From the workspace root:

```sh
pnpm install
pnpm --filter @workspace/deepali-portfolio run dev
```
